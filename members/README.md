# Member Images

ใส่ไฟล์รูปจริงไว้ในโฟลเดอร์นี้ เช่น `luca.jpg`

ใน Dev Mode ให้แก้สมาชิก Luca แล้วกรอกช่องรูปเป็น:

`members/luca.jpg`

จากนั้นต้อง push ทั้งโฟลเดอร์ขึ้น GitHub:

```powershell
git add .
git commit -m "Add member image"
git push origin main
```

ห้ามใช้ลิงก์หน้า GitHub แบบ `/blob/` โดยตรง ระบบจะแปลงให้ แต่ไฟล์ต้องมีอยู่จริงใน repository ก่อน
